Inrond.

One typeface. Every corner radius, from sharp to fully round.

Roundness is an axis, not a second font.

Rounded variants are usually separate families frozen at one setting. Inrond stores the sharp and the round design in one file and lets you pick any point between them, at any weight and optical size.

Type that follows your radius token.

Your buttons, inputs and cards already share one radius. Now the letters can share it too. Drag the slider: one number drives the components and the type.

It animates.

    
Roundness interpolates like weight does, so it can be a hover state, a theme switch or a scroll effect. Text never reflows: advance widths and kerning are identical at every roundness.

Inrond is built on Inter 4.1 by Rasmus Andersson and keeps its full character set, features, metrics and kerning. The cost of the axis is file size: about 2.5× Inter for the full font. Unicode-range subsets are provided; the Latin slice is 236 KB.

Every shape follows one rule.

    
Inrond is drawn as if by a round pen. Stroke ends become true round caps, outer corners take half the stroke width, and joins stay crisp. Drag the roundness slider at the top to see these change.

Use it.

    


/* 1. load */
@font-face {
  font-family: "Inrond";
  src: url("Inrond[ROND,opsz,wght].woff2") format("woff2");
  font-weight: 100 900;
  font-display: swap;
}

/* 2. pick a roundness, 0 to 100 */
body {
  font-family: "Inrond", sans-serif;
  font-variation-settings: "ROND" 60;
}

      

        
ROND 0 is the sharp design and matches Inter 4.1 outline for outline, so switching is free of layout shift.

        
Static families for apps without variable font support: Inrond Soft (50) and Inrond Round (100), nine weights each, roman and italic.
